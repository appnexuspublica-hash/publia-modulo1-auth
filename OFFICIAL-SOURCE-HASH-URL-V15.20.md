# Preservação de fragmentos em Fontes Oficiais — Governança v15.20

Correção para preservar fragmentos de URL usados como rotas funcionais por portais SPA.

Exemplo preservado:

`https://transparencia.betha.cloud/#/ZAA6t2_GdA4J1ZCwMJsJgw==`

A canonicalização continua removendo somente parâmetros de rastreamento conhecidos. O fragmento não é removido da URL clicável.
